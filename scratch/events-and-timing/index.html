Events + Timing

eventstiming

Start and control when things happen using the green flag, keys, and waits.

Milestones

  1. Trigger: Use a hat block to start a script on a flag or key press.
  2. Tempo: Insert waits to pace actions so humans can follow.
  3. Stack: Combine 3-5 blocks into a clear sequence.

Guide

Goal

Understand how events start scripts and how timing makes actions readable. Events are the "when" of your project. Timing controls the "how fast."

What to know

  • A hat block starts a script. Examples: green flag, key press, sprite clicked, and message received.
  • A project can have many event scripts.
  • wait blocks slow things down so players can understand what happened.
  • Too many scripts starting at once can be confusing. Give each script a clear job.

Try it

Build a start sequence on one sprite.

when green flag clicked
say [Ready] for (1) seconds
wait (0.5) seconds
say [Go!] for (1) seconds

Now add a second event to the same sprite.

when [space v] key pressed
say [Space action!] for (1) seconds
change color effect by (25)

Build a countdown

Use timing when the player needs warning before action starts.

when green flag clicked
say [3] for (1) seconds
say [2] for (1) seconds
say [1] for (1) seconds
say [Start!] for (1) seconds

Debugging event scripts

If nothing happens:

  1. Check which event should start the script.
  2. Press the right key or click the green flag.
  3. Make sure the blocks are connected under the hat block.
  4. Click the stack directly to test whether the blocks work without the event.

Level up

Add one more event:

when this sprite clicked
say [You clicked me.] for (1) seconds

Now your sprite can react to the flag, keyboard, and mouse.

Checkpoint

You can trigger the same sprite with multiple events and explain which event starts each script.
