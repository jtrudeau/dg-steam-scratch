Lists + Collections

listsdata

Store sets of data like quiz questions, inventory, or high scores.

Milestones

  1. Collect: Use lists to store multiple items.
  2. Pick: Choose a random or ordered item from a list.
  3. Update: Add or delete items as the project changes.

Guide

Goal

Use lists for collections that grow over time. A list is like a variable that can hold many items instead of one item.

Good uses for lists

  • Quiz questions and answers.
  • Inventory items.
  • Names of levels or scenes.
  • High scores.
  • Random prompts, facts, or clues.

Try it

Create a list of questions and display a random one.

when green flag clicked
add [Question A] to [questions v]
add [Question B] to [questions v]
say (item (pick random (1) to (length of [questions v])) of [questions v])

Build a simple quiz prompt

Create two lists:

  • questions
  • answers

Add matching items in the same order. Item 1 in questions should match item 1 in answers.

when green flag clicked
delete all of [questions v]
delete all of [answers v]
add [What color do you get from blue and yellow?] to [questions v]
add [green] to [answers v]
add [How many points to win Tiny Quest?] to [questions v]
add [5] to [answers v]
set [questionNumber v] to (pick random (1) to (length of [questions v]))
ask (item (questionNumber) of [questions v]) and wait
if <(answer) = (item (questionNumber) of [answers v])> then
  say [Correct!] for (2) seconds
else
  say [Try again next time.] for (2) seconds
end

Common list bugs

  • Question and answer do not match: keep matching items in the same position.
  • Old items appear again: use delete all of [list] under the green flag before adding items.
  • Random item is blank: pick from 1 to length of [list], not a fixed number that might be too large.

Checkpoint

You can store at least 3 items, pick one reliably, and explain why matching list positions matter.
