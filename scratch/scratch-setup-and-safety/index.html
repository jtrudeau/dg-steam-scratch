Scratch Setup + Safety Basics

setupaccountssafety

Create an account, set safe handles, and learn the program expectations for sharing projects.

Milestones

  1. Create account: Join Scratch with a school-safe username and verified email.
  2. Secure workspace: Save, rename, and verify you can open your project again.
  3. Sharing norms: Use only first names or initials in public notes and credits.

Guide

Goal

Make sure you can open Scratch, save your work, and share responsibly. Setup is not just a login step. It protects your work and your privacy.

Account rules for students

  • Use a school-safe username that does not include your full real name.
  • Keep your password private.
  • Use first names, initials, or team names in project notes.
  • Do not publish private contact information, addresses, personal emails, or school details.
  • Give credit when you remix ideas, images, sounds, or code.

Safe project notes

When you share a project, write notes like this:

Use arrow keys to move. Collect 5 stars to win. Made for DG-STEAM by Team Green.

Avoid notes like this:

My full name is... My phone is... My exact class is...

Try it

Use the visual walkthrough if you need it: /resources/setup.

Then create one new project and make a save test:

when green flag clicked
say [Account ready!] for (1) seconds

Rename the project Scratch Save Test. Leave the project, open it again, and check that the code is still there.

If you cannot sign in

Do not make a new random account without permission. Use the class setup process or ask an adult facilitator. While waiting, pair with a teammate and take the driver role after they finish a small step.

Checkpoint

You can open Scratch, create a project, rename it, find it again later, and explain what personal information should stay out of public project notes.
