My Blocks (Functions)

functionsreuse

Create reusable blocks to keep your scripts clean and readable.

Milestones

  1. Define: Create a new block for a repeated action.
  2. Reuse: Replace duplicated code with your block.
  3. Tune: Update one block to change behavior everywhere.

Guide

Goal

Reduce code duplication and make your project easier to edit. My Blocks are custom blocks. In other languages, this idea is often called a function.

When to make a block

Make a block when:

  • You repeat the same 3 or more blocks.
  • A script is getting hard to read.
  • You want a teammate to use an action without rebuilding it.
  • You want one edit to update the same action everywhere.

Try it

Turn a repeated animation into a custom block.

define wiggle
change x by (10)
change x by (-10)

Now use it in a script.

when [space v] key pressed
wiggle
say [Custom block!] for (1) seconds

Make a reusable reset block

Create a block called reset player.

define reset player
go to x: (0) y: (-80)
show
set size to (100) %
clear graphic effects

Use it under the green flag and after restart.

when green flag clicked
reset player

when I receive [restart v]
reset player

Naming rule

Use action names:

  • reset player
  • spawn star
  • show win message
  • play collect sound

Avoid vague names like thing, stuff, or do it.

Checkpoint

Your scripts are shorter, easier to scan, and use clear custom block names.
