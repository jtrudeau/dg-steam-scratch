Make Your First Sprite Say Hello

spriteslookseventsbasics

A friendly first build: choose a sprite, give it a safe greeting, animate it, and add one player interaction.

Steps

  1. Pick a buddy: Choose one sprite from the library or draw your own. Keep the project safe: no private names or contact details.
  2. Give them style: Use the Costumes tab to make one small change so the sprite feels like yours.
  3. Teach a greeting: In the Code tab, snap a `say` block under `when green flag clicked` so the sprite speaks when the project starts.
  4. Add a wiggle: Use motion and waits to make the greeting visible and fun.
  5. Show it off: Add a space-key reaction so the project is interactive, not just a one-time animation.

Guide

Build it

Select your sprite and add this script.

when green flag clicked
go to x: (0) y: (0)
say [Hello! I am ready to build.] for (2) seconds
move (20) steps
wait (0.5) seconds
move (-20) steps

Test with the green flag. The sprite should reset to the center, speak, move forward, pause, and move back.

Make it interactive

Add a second script.

when [space v] key pressed
next costume
say [You found my space-key action!] for (2) seconds

Now the player can do something. That is the difference between a poster and an interactive project.

Debug it

If nothing happens:

  1. Check that your sprite is selected.
  2. Check that the blocks are connected.
  3. Click the green flag for the first script.
  4. Press the space bar for the second script.
  5. Make sure the sprite is showing on the stage.

Level up

Change one thing:

  • Replace the message with a project instruction.
  • Add a sound after the space key.
  • Add a backdrop that matches your theme.
  • Add a second sprite that replies.
