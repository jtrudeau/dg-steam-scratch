Variables 101

variablesoperatorsscoring

Create, set, and change variables to track score, timers, and state reliably.

Steps

  1. Name with purpose: Use clear names like `score`, `timer`, or `scene` so teammates know what changes it.
  2. Always initialize: Under the green flag, `set` variables to starting values before any gameplay begins.
  3. Show or hide on stage: Toggle the checkbox for HUD values or hide them when you switch to cutscene backdrops.
  4. Combine with operators: Use `change` plus `if` checks to award points, track lives, or count completed tasks.
  5. Reset on retry: Add a broadcast (e.g., `restart`) that resets variables and positions so users can replay.

Guide

What a variable is

A variable is a named value that can change while the project runs. In Scratch, variables are perfect for score, timer, lives, level, energy, and story progress.

Build a score

Create a variable called score for all sprites.

when green flag clicked
set [score v] to (0)

Add points when something good happens.

when this sprite clicked
change [score v] by (1)

Build a win check

if <(score) = (5)> then
  broadcast [win v]
end

Debug checklist

  • Did you reset score under the green flag?
  • Is the code changing the same variable you are watching?
  • Is the change inside a forever loop that runs too fast?
  • Should the variable be "for all sprites" so every sprite can read it?

Done when

You can reset a variable, change it, display it, and use it in an if check.
